# 结构失败候选与人工补休止

结构检查失败时使用修复前的识别数据继续转调、渲染，保留失败原因且不授权核验通过下载。候选出口仍校验 PDF 有效性及文件哈希；不自动补缺失内容。没有可读 MusicXML 或渲染失败且没有有效 PDF 时仍报告失败。

编辑请求增加单独操作 `{type: "insertRests", measureId: "p1-m1", count: 7}`。只接受单声部单谱表、可靠拍号和时值单位、数字小节号，在指定小节后插入 1–64 个整小节休止；保留原小节内容和换页指令，后续数字小节号顺延。跨小节延音、非标准拍号等不支持的情况返回解释，不猜测。网页要求用户确认原谱内容确实为休止，保存成新版本。原有结构问题随新版本保留为未重新核验，不自动消除。

小节内部节奏缺口另提供 `{type: "confirmRest", gapId: "..."}`。客户端只能提交当前版本公开的缺口编号，小节、声部、拍点、时值、休止符种类及附点均由服务器绑定的 `rhythm-gaps.json` 和 `rest-classification.json` 提供。只有 Audiveris 内部对象唯一高分匹配、无多声部/连音等风险，并且用户在网页查看原 PDF 局部后明确确认时才写入。开头或内部缺口必须精确替换对应的 MusicXML `forward`，结尾缺口在右侧小节线前插入；写入前再次检查当前 XML 时间游标。弱候选只显示定位，不提供快速补入。每次保存仍生成独立候选版本和 PDF，未处理的建议会带入下一版本。
